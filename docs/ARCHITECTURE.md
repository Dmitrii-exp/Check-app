# Архитектура Check App

Текущая версия разделена на три основных слоя:

1. HTML — интерфейс и модальные окна.
2. CSS — визуальное оформление.
3. JavaScript — авторизация, Supabase, оборудование, ТО, задачи, история, отчёты, подписки и Super Admin.

## Данные

Supabase используется для:
- Auth;
- профилей пользователей;
- компаний;
- подразделений;
- оборудования;
- регламентов ТО;
- задач;
- выполненных работ;
- подписок;
- Storage фотографий.

## Следующий этап

Перед публикацией в Google Play / App Store рекомендуется:
- вынести конфигурацию Supabase из исходника в безопасную конфигурацию сборки;
- проверить RLS;
- подключить реальную платёжную систему;
- добавить PWA/Capacitor;
- проверить Android и iOS на реальных устройствах;
- устранить неиспользуемые/старые обработчики событий.
