# Password recovery — mobile integration

The recovery redirect is `ru.checkapp.mobile://recovery` for native Android and iOS, and `https://www.app-check.ru/` for the web version.

**Supabase Dashboard configuration required:** Authentication → URL Configuration → Redirect URLs → add exactly `ru.checkapp.mobile://recovery`. Without this allow-list entry, Supabase will reject or replace the redirect and the recovery link will not open the native app.

Android: after `npx cap add android && npx cap sync android`, run `node scripts/configure-mobile-links.mjs android`.

iOS: on macOS, after `npx cap add ios && npx cap sync ios`, run `node scripts/configure-mobile-links.mjs ios`.

Verify end-to-end on physical devices:
1. Request password reset from native app.
2. Open emailed link on same device.
3. Confirm the app opens the reset screen.
4. Enter new password twice, test mismatch and minimum length.
5. Save and log in with the new password.
6. Test expired and already-used links.

**Important:** Native URL schemes are not verified app links; another app may register the same scheme. Do not treat the deep link itself as authorization; only accept a Supabase-validated session. For production, consider verified Android App Links and iOS Universal Links.

No APK or IPA is generated by this change.
